# Starter · Rebel-I ONG donor dashboard

Start here. This folder contains only what you'd have after the first client call:

- `docs/web-app.plan.md`: the MVP plan (scope, API, screens, tests, assumptions)
- `docs/web-app.spec.md`: the client-facing brief
- `data/donations.csv`: a sample export (14 donations); `data/donations-with-errors.csv` has two bad rows

Next steps:

```bash
npm install -g @fission-ai/openspec@latest
openspec init
```
